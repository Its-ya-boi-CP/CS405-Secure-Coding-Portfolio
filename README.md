# CS 405 Secure Coding Portfolio

Coden Polk's CS 405 portfolio brings together security policy, a presentation, coding activities, and a final journal reflection. The work covers secure coding standards, input validation, memory safety, SQL injection prevention, exception handling, encryption, static analysis, security testing, defense in depth, and DevSecOps.
